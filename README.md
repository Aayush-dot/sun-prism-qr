# Photostable "Find it near you" (concept demo)

Concept demo for Sun Pharma's Sun Prism Season 2 case competition (Team Rajma Chawal, SPJIMR). Chemist data is illustrative.

## Deploy on GitHub Pages
1. Upload `index.html` and the `assets` folder to the repository root (keep the folder).
2. Settings → Pages → Deploy from a branch → `main` / root → Save.

## Links for QR codes
- Home link (no product): `https://aayush-dot.github.io/sun-prism-qr/`. Add `?sku=acne` etc. to pre-select a product. The map always shows Andheri, Mumbai.
- sku: `gold`, `acne`, `pro`, `emulgel`, `entry` (or leave it out to show all products).

## Pack photo
- `assets/photostable-gold.png` is shown for every product in this demo.
